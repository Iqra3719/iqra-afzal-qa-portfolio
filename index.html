    About

    I started in manual QA: writing test cases, finding defects, and learning how real releases break. Across almost two years of hands-on testing, most recently on large-scale financial web and mobile applications for a UK-based organization, I built the habit of thinking about risk before running a single test.

    In September 2026 I completed a QA/SDET internship at Ahmad Institute and moved that foundation into automation. I built a Playwright and JavaScript framework with the Page Object Model, automated REST APIs, added CI with GitHub Actions and Azure Pipelines, validated data in MySQL, and tested an Android app for security issues.

    What I find most interesting is AI testing. I test AI-powered applications for hallucination, bias and prompt injection with automated, repeatable checks. I do not build AI models; I check that AI features behave safely and correctly.

    I keep learning by building small, practical projects, and I am now adding JMeter to my performance-testing toolkit.
